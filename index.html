System Requirements

  • Windows: Windows 10/11 (64-bit)
  • macOS: macOS 11 (Big Sur) or later (Apple Silicon)
  • Optional: FFmpeg for audio/video features

Installation

Windows

  • Download the .exe installer
  • Run the installer and follow the prompts
  • Windows may show a security warning — click "More info" and "Run anyway"

macOS

  • Download the .zip file
  • Extract and drag Pixel Pig to your Applications folder
  • Right-click the app and select "Open" to bypass Gatekeeper on first launch
