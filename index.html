Why it exists

AI creation is fun. AI production gets messy.

Models move fast — this week wins on motion, next week on faces, then prices change again. For quick tests, web apps are fine. But a longer project turns into scattered downloads, lost prompts, expiring credits, and outputs no one can trace. Pixel Pig is built for that mess. It rolls in data, not mud.

Outgrow one web app

Pick the model that fits the shot — image, video, audio, speech, and 3D — like the work creators already do across Kling, Vidu, Runway, Midjourney, Higgsfield, Magnific, Topaz, ElevenLabs, and ComfyUI.

Track the creative trail

Keep prompts, source images, settings, and outputs easy to follow from idea to final edit. No more folders of mystery filenames.

Batch the boring stuff

Run variations, aspect ratios, and prompt tests without rebuilding the same job over and over.

Keep files local

Download, compare, crop, convert, and extract frames without leaving the app.

How people use it

Concept passes

Test one prompt across multiple image models, compare, and keep only the contenders.

Video iteration

Move from stills to image-to-video without losing the prompt and source trail.

Asset wrangling

Sort outputs, prep files, and convert formats so the boring parts stay out of the way.

Final polish

Combine clips and add audio with FFmpeg bundled in — no separate editor required.

Heads up

Before you install.

Requirements

  • Windows 10/11, 64-bit.
  • macOS 11 or later, Apple Silicon.

First-run quirks

  • Windows may require “More info” then “Run anyway”.
  • On macOS, use right-click then “Open” the first time.

Provider keys

  • Add a Fal, Replicate, Kie.ai, or ComfyUI key before you generate.
  • Open an issue if a model you need is missing.
